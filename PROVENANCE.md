# Provenance

StarshipMania private team staging derives from **ProjectZero First Playable Demo v0.4.3**, commit **3aa4bd12dbe510423f518faa8a9053fa62e42808** (2026-09-10), source subtree **prototypes/first-playable-demo/**.

Inherited from that revision: the procedural arena and renderer, control and tracking implementation, synthetic observations, calibration and guided practice, two Padisarah units, manual Deploy/Recall, and deterministic Fire at Will policies A/B. The source and TypeScript tests are pre-existing work. New drone agents are absent; they belong to later revisions and are not imported.

Changes for this staging export: package scripts and setup documentation, optional webcam asset preflight and failure handling, setup-only local model and runtime pin validation, gated model QA checks, and focused preflight/camera regression tests. No new gameplay or autonomous drone behavior. The synthetic path uses no camera or model. No repository history, private QA material, generated files or webcam payloads are supplied.
